# agent-config

This is a repo for shared agent config, that should be used across multiple repos. 

# How tos

- install the agent config to a new repo via

```shell
git submodule add git@github.com:pascalbe-dev/agent-config.git .claude
```

- get the latest version of the agent config after initial installation via

```shell
git submodule update --remote --merge
```
